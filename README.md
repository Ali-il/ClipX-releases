# ClipX — releases

Download page for **ClipX**, a small Android clipboard manager. It saves text only
when you ask (Quick Settings tile, share menu, text-selection menu or the Paste
button), keeps everything on the phone, and asks for no permissions.

Grab the latest APK from **[Releases](../../releases/latest)**, or track this repo
in Komi Store / Obtainium to get updates automatically.

(The source code lives in a separate private repo; this one only hosts builds.)
